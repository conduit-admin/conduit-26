# Кондуит

Учёт плюсов на математической смене: кондуиты по дням, общий рейтинг и
пересчёт рейтинга по любому подмножеству серий и тем.

Сайт открывается по ссылке, читать может кто угодно, писать — только владелец
репозитория. Никакого сервера и базы данных нет: страница читает файлы из
`data/` и считает всё в браузере читателя.

## Как считаются баллы

Вес задачи = **число учеников на смене − число решивших её**. Число учеников
задаётся один раз в начале смены (`students_total` в `data/config.json`) и
дальше не меняется. Задача, которую сдали трое из тридцати, стоит 27 баллов;
задача, которую сдали все, — 0.

Вес зависит только от самой задачи, поэтому при любом фильтре баллы за неё не
меняются и рейтинги сопоставимы между собой.

Порядок в рейтинге: сначала очки, при равенстве — по алфавиту. Место у каждого
своё, одинаковых мест не бывает.

## Что где лежит

```
index.html          страница: рейтинг, кондуиты, карточка ученика
edit.html           редактор: ввод кондуита с телефона
assets/             стили и скрипты
data/
  config.json       название смены, число учеников
  types.json        темы: разделы и подразделы
  students.json     список учеников
  graves.json       гробарий: задачи вне серий
  series/NN.json    кондуит одного дня
  series/manifest.json  список файлов серий
tools/build.py      сборка offline.html — копии сайта одним файлом
offline.html        снимок сайта одним файлом: открывается без интернета
```

## Формат серии

```json
{
  "n": 7,
  "date": "2026-08-03",
  "kind": "series",
  "problems": [
    { "id": "0", "type": "algebra", "sub": "inequalities", "exercise": true },
    { "id": "1", "type": "comb", "sub": "graphs", "exercise": false },
    { "id": "2а", "type": "numbers", "sub": null, "exercise": false }
  ],
  "solved": {
    "ivanov-artem": ["1", "2а"],
    "petrova-masha": []
  }
}
```

`kind` — что было в этот день: `series` (по умолчанию), `off` — выходной,
`battle` — математический бой. Выходной и матбой занимают номер и дату, но
задач не несут: в фильтрах рейтинга их нет, в списке дней они видны, чтобы был
виден ритм смены.

Единица зачёта — задача целиком или её пункт (`5а`, `5б`): у каждой свой вес.
`type` — раздел из `types.json`, `sub` — подраздел; `null` только у разделов
без подразбиения.

Если подраздел задачи отсутствует в `types.json` — например, его удалили —
задача остаётся **без темы**: в рейтинг она не идёт, пока ей не выберут тему
заново. В кондуите она при этом видна, но с серой полоской вместо цветной, а в
редакторе помечена серым кружком и вопросом вместо названия подраздела.

`exercise` — вид задания, признак, не связанный с темой. Упражнения идут под
нулевым номером (`0`, `0а`, `0б`) и на сайте фильтруются отдельно: в рейтинге
есть переключатель «Что считаем — задачи / упражнения».

## Гробарий

Особо сложные задачи, которые копятся всю смену и не привязаны ко дню. Номер
всегда `Гn`, живут в `data/graves.json`:

```json
{
  "problems": [
    { "id": "Г1", "type": "geometry", "sub": "stereometry" },
    { "id": "Г2", "type": "comb", "sub": "graphs" }
  ],
  "solved": {
    "ivanov-artem": ["Г1"],
    "petrova-masha": []
  }
}
```

Вес считается той же формулой, поэтому гроб, который взял один человек, стоит
почти в цену смены. В рейтинге у гробов свой переключатель — их видно и без
них. Отбор по сериям на них не действует: дня у них нет, поэтому «ни одной
серии» плюс включённые гробы даёт рейтинг по одному гробарию.

## Редактор

`edit.html` на том же сайте — страница ввода. Открывается в браузере телефона,
сервера не требует: правки уходят прямо в этот репозиторий через GitHub API,
а сайт после коммита выкладывается сам.

Что нужно один раз: вкладка **Доступ** → вставить fine-grained токен с доступом
только к этому репозиторию и правом **Contents: Read and write**. Токен лежит в
localStorage браузера и уходит только на `api.github.com`. Если телефон
потерялся — отозвать токен в настройках GitHub.

Черновиков на диске нет: правки живут в памяти страницы и уходят в репозиторий
по кнопке во вкладке «Сохранение». Уход со страницы их теряет, ничего не
переспрашивая; переключение между днями — нет.

Редактор и сайт независимы: это две разные страницы, переходов между ними в
интерфейсе нет.

- **Дни** — лента дней; «+ день» заводит новый и сразу ставит его в ленту, как
  подраздел в темах. В репозиторий он уедет позже, из вкладки «Сохранение».
  У дня задаются номер, дата и что в нём было (серия, выходной, матбой), а для
  серии — список задач с темами и сетка «ученики × задачи». Правки каждого дня
  живут отдельно: переход на другой день ничего не теряет. Касание клетки ставит и снимает плюс. Внизу видно,
  сколько человек решило каждую задачу и сколько она стоит. Там же кнопка
  удаления серии — она спрашивает подтверждение.
- **+ пункт** превращает задачу `5` в `5а` и добавляет `5б`; плюсы при
  переименовании не теряются.
- **Гробы** — тот же список и та же сетка, но без дат и номеров: «+ гроб» даёт
  следующий свободный `Гn`, тема выбирается так же, как у задачи серии.
- **Темы** — добавление и удаление подразделов, добавление раздела. Правка сразу
  доступна при разметке задач, но в репозиторий не уходит, пока не нажата
  кнопка; уже записанные серии не меняются. Удаление подраздела спрашивает
  дважды: задачи из него останутся без темы и выпадут из рейтинга, пока им не
  выберут тему заново.
- **Сохранение** — единственное место, откуда что-либо уезжает в репозиторий, и
  там же токен. Добавление и удаление дня до этой кнопки меняют только экран
  редактора. Одна кнопка отправляет всё накопленное: темы, затем записанные дни,
  затем удаления, затем гробарий, и последним — одной записью — список дней.
  Между сохранениями две минуты перерыва, отметка лежит в localStorage, поэтому
  перезагрузка её не обходит. Рядом кнопка отката — она выбрасывает все правки и
  возвращает то, что на сайте. Если у каких-то задач подраздела больше
  нет, вкладка показывает их списком: они не считаются, пока им не выберут тему
  заново.
- Только что сохранённая серия помечается «ждём», пока Pages не переразвернёт
  страницу — чтобы её нельзя было случайно создать заново поверх сохранённой.

Чего редактор пока не умеет: работать при полностью отсутствующем интернете
(страница не закеширована, нужен service worker) и править список учеников.

## Как обновляется сайт

Любое изменение файлов в ветке `main` GitHub Pages выкладывает сам, обычно
меньше чем за минуту. Отдельной кнопки «опубликовать» нет.

Офлайн-копия — снимок на момент сборки, её надо пересобирать вручную:

```
python tools/build.py
```
