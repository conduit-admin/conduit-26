# Данные для имитации

Смена, придуманная целиком: 16 серий подряд с 8 августа, два выходных и матбой
в середине, семь задач в серии, часть с пунктами, упражнения под нулевым
номером. Плюсы расставлены по силе ученика и трудности задачи, поэтому веса и
рейтинг выглядят как настоящие.

Сайт эти файлы не читает — он смотрит только в `data/`. Лежат они здесь, чтобы
было на чём проверять правки, не трогая настоящую смену.

Вернуть их на сайт:

```
cp demo/series/*.json data/series/
cp demo/graves.json data/graves.json
python tools/build.py
```

Чтобы убрать обратно, достаточно удалить всё из `data/series/` кроме
`manifest.json`, а в самом `manifest.json` оставить `{"series": []}`;
`data/graves.json` — `{"problems": [], "solved": {}}`.
